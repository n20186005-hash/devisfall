# Local validation scope

Use exact Node 24.20.0 and pnpm 12.3.4 with the frozen dependency lockfiles and three reviewed lifecycle selectors. Normal install, check, build and the default Wrangler dry-run are separate gates; local results do not establish a published version, actual admission, browser layout or production interactions.

The source retains static Astro pages and the original language routes, map, photographs, dialogs, optional analytics and offline resource handling. The Worker provides canonical host/protocol handling before Static Assets and genuine localized error responses. Browser, official build/deployment and production verification remain independent release checks.
